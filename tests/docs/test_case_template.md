## 测试用例描述

### 1. 测试目标
验证获取所有笔记接口的正常功能，确保接口能够正确返回笔记列表。

### 2. 测试前置条件
- 后端服务已启动
- 数据库连接正常
- 至少存在一条笔记数据

### 3. 测试步骤

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 发送GET请求到 `/api/notes/` | 请求发送成功 |
| 2 | 验证响应状态码 | 状态码为200 |
| 3 | 验证响应体格式 | 响应体为JSON数组 |
| 4 | 验证响应时间 | 响应时间小于2秒 |

### 4. 测试数据

```json
{
  "request": {
    "method": "GET",
    "url": "/api/notes/",
    "headers": {
      "Content-Type": "application/json"
    }
  },
  "response": {
    "status_code": 200,
    "content_type": "application/json",
    "body": [
      {
        "_id": "string",
        "title": "string",
        "content": "string",
        "createdAt": "datetime",
        "updatedAt": "datetime"
      }
    ]
  }
}
```

### 5. 预期结果

1. **状态码**：200
2. **响应体**：JSON数组格式
3. **响应时间**：小于2秒
4. **数据格式**：包含_id、title、content等字段
